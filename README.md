# Superhero Punchlines

*Saving the world, one terrible joke at a time.*

A comic-book-styled superhero joke generator built for the **Week 6 Mobile Web Development** assignment using AI-assisted (agentic) development.

## Tech stack

| Category | Technology |
|---|---|
| Framework | React 19 |
| Language | TypeScript |
| UI component library | daisyUI 5 |
| Styling | Tailwind CSS 4 |
| Build system | Vite 7 |
| Routing | React Router 7 |
| Persistence | Browser localStorage |
| Hosting | Firebase Hosting |

## Commands (run in this folder)

| Command | What it does |
|---|---|
| `npm install` | Installs dependencies (only needed once, or after deleting `node_modules`) |
| `npm run dev` | Starts the local development server (http://localhost:5173) |
| `npm run build` | Type-checks with TypeScript, then compiles and minifies the app into **`deploy/`** |
| `npm run preview` | Serves the production build from `deploy/` locally (http://localhost:4173) |
| `firebase deploy` | Publishes the `deploy/` folder to Firebase Hosting |

## Project structure

```
Joke Generator/
├─ index.html              App shell (applies saved theme before first paint)
├─ vite.config.ts          Vite config — build output set to "deploy"
├─ firebase.json           Firebase Hosting: public dir "deploy" + SPA rewrite
├─ package.json            Scripts and dependencies
├─ public/                 Static files copied as-is (favicon)
├─ deploy/                 PRODUCTION BUILD OUTPUT (generated by npm run build)
└─ src/
   ├─ main.tsx             Entry point: fonts, styles, providers, routes
   ├─ components/          Reusable UI (Header, TabBar, JokePanel, CategoryPicker, ActionBurst...)
   ├─ pages/               Home, Favorites, Settings, About, Help, NotFound
   ├─ data/                jokes.ts (72 editable jokes) and categories.ts
   ├─ hooks/               Settings, favorites, toast/announcements, joke deck, media queries
   ├─ utils/               localStorage helpers, clipboard, shuffle/deck logic
   ├─ types/               Shared TypeScript types
   └─ styles/main.css      Tailwind + daisyUI themes + comic design system
```

## Editing jokes

Open `src/data/jokes.ts`. Each joke has an `id`, a `category` (`marvel`, `dc`, or `versus`), the `characters` it mentions, and either `setup` + `punchline` (two-part) or `text` (one-liner). Save, then run `npm run build` again.
